# Agent instructions

## Public-facing work

- Before any public-facing post or edit, show the exact final text or action to the user and get explicit approval. This includes pull request titles and descriptions, comments, reviews, issues, and release notes. Never post, edit, or delete public content automatically.
- For public-facing timed work, read and follow `/Users/wsb/.codex/skills/even-git/SKILL.md`, including its allowed-minute rules. This applies to PRs, comments, and other public posts as well as Git operations. Wait for an allowed minute when needed.
- Publish only the approved text, unchanged. Verify the destination and current checks before posting when checks apply.
- Keep the language consistent within each public-facing item. Prefer English by default; use Russian when it suits the Russian-language repository or audience. Do not translate or transliterate Russian unnecessarily.
- Always speak to the user in English. Russian may be used in repository-facing content when appropriate.

## Git and repository changes

- Preserve unrelated work and stage only files belonging to the current task.
- When a turn changes repository files, create a local commit or amend the current local commit before ending the turn. Follow the even-git skill for commit naming, timing, and timestamps.
- Never push without the user's explicit authorization.
